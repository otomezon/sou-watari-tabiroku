# 層渡りの旅録 v5.0.5

モンスターのゴールド報酬を少し抑え、難易度が高いほどレア個体が出やすくなるパッチリリースです。

- 通常モンスターのゴールドドロップ率を難易度別に引き下げ（初級相当 28% → 23%、最上級 40% → 32%）。
- ゴールド獲得量の倍率を通常個体 0.85倍 → 0.75倍、レア個体 2倍 → 1.5倍に調整。
- レア個体の総出現率を初級 6.2%、中級 6.8%、上級 7.4%、最上級 8.0%へ段階的に上昇。
- チュートリアルではレア個体なし、初級では魔喰いなしの従来ルールを維持。
- 非ゴールドのドロップ率、レア個体のプレミアム戦利品、魔喰いの能力は変更していません。
- セーブスキーマ12を維持。既存の冒険データをそのまま利用できます。
