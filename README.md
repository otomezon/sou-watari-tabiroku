# 層渡りの旅録 v5.1.0

最深階を大広間のボスステージに刷新しました。ボスは2×2マスを占有する大型キャラクターとして表示され、プレイヤーの攻撃判定・ボスの移動と攻撃・セーブ検証も4マスの占有範囲に対応します。大型化に合わせてボスのHPを15%、攻撃力を10%強化し、防御力を2上げました。

セーブスキーマ12は維持しています。既存の最深階セーブは、次回ロード時にボスの残HPを保ったまま大広間へ移行します。
