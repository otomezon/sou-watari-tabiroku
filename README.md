# 層渡りの旅録 v5.1.15

回復アイテムの旧固定回復仕様と、全キャンペーンのボス戦バランスを修正しました。

- 回復薬はv5.1.11変更前のアイテム定義値と1.75倍補正に復帰。最大HPに依存しない固定HP回復です。
- チュートリアルのボスは単独・通常行動にし、遠距離範囲攻撃や強化形態をなくしました。
- 初級〜最上級もボスHP・攻撃・防御、形態補正、範囲攻撃率、護衛数を個別に調整しました。
- 旧セーブのボス戦も残りHP割合を保って新しい能力値へ一度だけ更新します。
