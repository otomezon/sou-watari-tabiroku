# 層渡りの旅録 v4.9.1

v4.9.0のサウンド改善パッチです。

- レベルアップファンファーレを、短い上昇メロディと最後の明るい和音で構成したオリジナル音源へ再制作。約1.58秒、Cメジャー、金管風リード＋ストリングス＋短いベルのアクセント。
- トルネコなどのクラシックなダンジョンRPGの「冒険感」「短く明快な達成感」を参考にした音作り。既存作品の旋律・録音・音源は使用していません。
- 倍速敵の2回被弾は、通常の被弾音と同じ音を0.24秒間隔で2回鳴らす方式に変更。音色・音程の変化は付けません。
- レベルアップ音と同じターンの被弾音も、ファンファーレの長さに合わせて後続再生の開始を短縮。
- セーブスキーマv11を維持。既存セーブの移行は不要。
