# 層渡りの旅録 v5.2.0

5つの難易度・全フロアの敵バランスを見直し、フロア全体の敵数も含めた段階的な難易度曲線にしました。

## 全フロアの敵バランス

各ダンジョンの1階から最終階まで、平均的な敵戦闘力の目標を滑らかな曲線で上げます。

| 難易度 | 1階の目標 | 最終階の目標 |
|---|---:|---:|
| チュートリアル | 60% | 66% |
| 初級 | 64% | 69% |
| 中級 | 68% | 74% |
| 上級 | 67% | 73% |
| 最上級 | 76% | 84% |

上級は中級より敵の出現数が多いため、敵1体あたりの目標をわずかに抑えています。フロア全体では上級の方が高い圧力になります。敵補正の上限は全難易度1.45に統一し、階層によって補正が上限に張り付いて成長が不自然に途切れる場面を減らします。

## 冒険開始時の食料

新しい冒険では、既存の1階向け食料テンプレートから1つを所持して開始します。新しい食料アイテムは追加していません。初期装備もありません。

## これまでの改善

- モンスターが階段マスを経由して追跡できるように修正。
- ドラゴンのブレスをモンスター起点の射線として描画・判定し、射線上の敵にもダメージを与えます。
- モンスター専用のレベルアップファンファーレを追加。
- 武器の耐久消耗を2回の攻撃につき1回に緩和。
- 反射特性の希少個体を追加。
- 金貨の通常ドロップ率を0.88倍に抑え、装備・換金品・薬・食料のドロップ率を増加。
- 地面の武器・盾・鎧・食料・薬・換金品を種類別のシルエットで表示。

## セーブ互換性

通常敵のバランスバージョンをv6へ更新します。既存敵の現在HP割合を保ち、v1〜v5それぞれの旧補正から差分移行します。セーブスキーマ12とボス本体の基本性能は維持します。
