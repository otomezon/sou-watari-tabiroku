# 層渡りの旅録 v5.2.2

5つの難易度・全フロアの敵バランスを見直し、フロア全体の敵数も含めた段階的な難易度曲線にしました。

## v5.2.1 パッチ修正

- 敵同士が進路を塞いだ時、空いている隣接マスへ小さく回避して再接近するようにし、無関係な方向へ大回りする動きを抑制。
- プレミアム報酬でも現在階より先のアイテムテンプレートは選ばず、強化品質だけを上げるように変更。
- プレイヤーの全ターン操作に短い間を追加。ゲームオーバー時は最後の被弾表示を残してから結果画面に切り替え。
- 探索中にボスBGMを先読みし、ボス階への切り替えを高速化。

詳細: [PATCH_NOTES_v5.2.1.md](PATCH_NOTES_v5.2.1.md)

## 全フロアの敵バランス

各ダンジョンの1階から最終階まで、平均的な敵戦闘力の目標を滑らかな曲線で上げます。

| 難易度 | 1階の目標 | 最終階の目標 |
|---|---:|---:|
| チュートリアル | 62% | 68% |
| 初級 | 72% | 80% |
| 中級 | 80% | 90% |
| 上級 | 88% | 98% |
| 最上級 | 98% | 110% |

上級は中級より敵の出現数が多いため、敵1体あたりの目標をわずかに抑えています。フロア全体では上級の方が高い圧力になります。敵補正の上限はチュートリアル1.22、初級1.32、中級1.42、上級1.52、最上級1.62です。敵の基礎能力と上位ランクの投入速度も合わせて各階層の圧力を調整します。 上級の上位ランクは終盤に分散して導入し、最終階までに最上位へ到達します。

## 冒険開始時の食料

新しい冒険では、既存の1階向け食料テンプレートから1つを所持して開始します。新しい食料アイテムは追加していません。初期装備もありません。

## これまでの改善

- モンスターが階段マスを経由して追跡できるように修正。
- ドラゴンのブレスをモンスター起点の射線として描画・判定し、射線上の敵にもダメージを与えます。
- モンスター専用のレベルアップファンファーレを追加。
- 武器の耐久消耗を2回の攻撃につき1回に緩和。
- 反射特性の希少個体を追加。
- 金貨の通常ドロップ率を0.88倍に抑え、装備・換金品・薬・食料のドロップ率を調整。
- 地面の武器・盾・鎧・食料・薬・換金品を種類別のシルエットで表示。

## セーブ互換性

通常敵のバランスバージョンをv6へ更新します。既存敵の現在HP割合を保ち、v1〜v5それぞれの旧補正から差分移行します。セーブスキーマ12とボス本体の基本性能は維持します。
