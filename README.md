# 層渡りの旅録 v4.9.3

v4.9.2からのタイトル画面・プレイHUD改善パッチです。

- タイトル画面のダンジョン選択で、初級に付いていた「おすすめ」表示を削除しました。すべてのダンジョンを同じ優先度で選べます。
- プレイ中の上部情報を再整理。ダンジョン名と現在階を分け、現在階を大きく独立して表示します。
- 現在階は必ず「地下 N 階」と表示し、最深部でも階数を省略しません。最深部の案内はダンジョン名の横に併記します。
- ターン数と所持金を階数表示から分離し、数字が増えても階数が途切れない構成にしました。
- セーブスキーマv11を維持。ゲームバランス、敵AI、マップ生成、音声処理に変更はありません。

## Hosting

Cloudflare PagesはGitHub連携でmainブランチへの更新を自動デプロイします。公開ルートはリポジトリ直下のindex.html、assets/、audio/、icons/、sw.js、manifest.webmanifestです。
