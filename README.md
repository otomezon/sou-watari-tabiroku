# 層渡りの旅録 v5.1.2

全5ダンジョンの最序盤（地下1〜2階）を再調整しました。

- 新規冒険では武器・盾・防具を初期装備し、食料1個と回復薬1個を所持して開始します。
- 地下1階の敵数を従来より2体、地下2階を1体減らし、序盤の敵能力値も5%抑えます。
- 地下1〜2階では敵を開始地点から4マス以上離して配置し、希少個体は地下3階から出現します。
- 中盤以降の敵数・難易度・希少個体率、ボス、大広間、セーブスキーマ12は維持します。
