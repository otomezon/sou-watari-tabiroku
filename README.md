# 層渡りの旅録 v5.1.10

v5.1.9の希少モンスター撃破エラー修正を維持し、魔喰いを倒したモンスターの成長演出を補完しました。

- 魔喰いを撃退したモンスターは、既存の成長処理によりレベル・最大HP・攻撃・防御が上昇。実際にレベルが上がった場合はレベルアップのファンファーレを再生。
- レベル上限のモンスターには成長音を鳴らさず、上限到達メッセージを表示。
- 魔喰い撃退後の成長とファンファーレ通知を検証する回帰テストを追加。
- セーブスキーマ12、v5.1.8〜v5.1.9のゲームバランス修正を維持。
