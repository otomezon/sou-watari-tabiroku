# 層渡りの旅録 v5.1.12

5つのダンジョンの全フロアを対象に、序盤の過度な弱体化、敵数の立ち上がり、敵 tier の切り替わりを再調整しました。

- 初階に重なっていた0.95倍・0.80倍の敵能力補正を撤廃し、各難易度の本来の能力倍率へ戻しました。
- 1〜2階の敵数は標準より1体少なく、3階はチュートリアル以外で50%の確率で1体少ない波にして、通常密度へ段階的に移行します（チュートリアルは控えめな出現数を維持）。
- チュートリアル以外は希少個体を1階から抽選。初級では魔喰いを引き続き除外します。
- 全キャンペーンの各階に深度補正を加え、深層ほど敵能力が滑らかに上昇。
- 上位 tier の敵は切り替わり初期だけ能力を6%抑え、移行完了時に本来の能力へ戻します。
- 最上級の第6 tier は25〜29階にかけて登場率を段階化し、25階の急変を緩和。
- セーブスキーマ12と、既存の店・回復・ボス仕様を維持。
