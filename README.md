# 層渡りの旅録 v5.1.19

通常モンスターの撃破率を40%とする保守的な成長想定へ変更し、装備品が揃わない周回でも進行できるよう、敵の平均戦闘力を再調整しました。

- ボス階到達時の想定プレイヤーLvは、チュートリアル3／初級7／中級12／上級20／最上級27です。
- 通常敵の目標戦闘力は、装備なしのプレイヤー基礎戦闘力に対して難易度順に48%／56%／64%／72%／80%です。
- 旧バランスv1・v2のセーブデータは、旧補正との差分だけを一度反映し、現在HP割合を維持します。
- ドラゴンの炎・氷ブレスは横幅1マス、縦5マス。満腹度5行動ごとの減少とレベルアップ演出の同期再生も維持します。
- セーブスキーマ12は変更していません。
