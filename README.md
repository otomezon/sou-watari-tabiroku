# 層渡りの旅録 v5.1.2

全5ダンジョンの最序盤（地下1〜2階）を再調整しました。初期アイテムなしのゲーム設計は維持します。

- 初期装備・初期所持品は従来どおり付与しません。
- 地下1階の敵数を従来より2体、地下2階を1体減らし、最低出現数は2体です。
- 地下1〜2階の敵能力値を5%抑えます。
- 地下1〜2階では敵を開始地点から4マス以上離して配置し、希少個体は地下3階から出現します。
- 中盤以降の敵数・難易度・希少個体率、ボス、大広間、セーブスキーマ12は維持します。
