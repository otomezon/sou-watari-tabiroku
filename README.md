# 層渡りの旅録 v5.1.11

序盤の難易度、最上級終盤の敵 tier 移行、敵AI、ボス戦、ショップ価格、HP回復方式を調整しました。

- 全5ダンジョンの地下1階は敵の能力値を抑え、魔喰いなどの希少個体は出現しません。
- 最上級は地下25階以降の最終系統への移行を緩やかにし、深層の急激な敵更新を抑制。
- 魔喰いはモンスターを攻撃した行動中に、主人公へ続けて攻撃しないよう修正。
- 店主は追跡中に他の魔物が進路を塞いでいる場合、その魔物を倒して追跡を継続。攻撃力も強化。
- ボスに範囲攻撃と予告エフェクトを追加。
- 最上位装備の購入価格を引き上げ。
- 回復薬と自然回復を最大HP比率へ変更。セーブスキーマ12は維持。
