# 層渡りの旅録 v5.1.8

最上級ダンジョン終盤の敵の強さと、中盤以降のゲーム内経済を調整しました。

- 最上級の通常敵は地下21〜30階で補正を段階的に緩和し、地下30階で最大6%の抑制に留めます。
- 地下26階以降の「魔喰い」と「剛腕」形態の急激な攻撃・耐久上昇を個別に抑え、他の難易度・階層は維持します。
- 中級以上のゴールド・換金品ドロップを抑え、希少個体のゴールド倍率も縮小します。
- 上位回復薬・高回復食料・高性能装備は効果に応じて価格を上げ、序盤の基本消耗品価格は維持します。
- 最上級終盤での換金品売却益も段階的に調整します。
- 初期装備なし、初期所持品なし、セーブスキーマ12は維持します。
