# 層渡りの旅録 v4.9.4

v4.9.3からの探索画面レイアウト再調整パッチです。

- 階数表示をコンパクトな横1行に戻しました。
- TURN・GOLDをLEVEL・EXP・攻撃・防御の右側へ同じ行内に集約しました。
- プレイ画面の左右余白と探索エリアの余白を縮小し、探索マップを前版より大きく表示します。
- 操作ボタンのタップ領域は48px以上を維持します。
- セーブスキーマv11を維持。既存セーブの移行は不要です。
