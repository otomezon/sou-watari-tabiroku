# 層渡りの旅録 v5.2.2

全キャンペーンの敵強度と戦利品の出現量を再調整し、敵の隊列移動と攻撃時の例外も修正しました。

## v5.2.2 パッチ修正

- 敵の出現数・構成は元のまま維持。チュートリアル・初級・中級・最上級の敵個体目標値を小幅に上げ、上級は元の個体目標値を維持。
- 床に置かれるアイテムの出現率を32〜44%へ低下。通常敵・希少敵の装備や回復品などのドロップ率も低下。
- 敵の占有マスを重み付き経路として扱い、進むたびにプレイヤーへの経路コストを減らすことで、前後に揺れる移動を防止。
- 無効な攻撃方向や敵・装備の不正な数値を検証。閉じた音声コンテキストを再生成し、効果音の例外が攻撃処理を中断しないよう修正。
- 敵が階段マスに立った状態も正規の配置として保存できるよう、セーブ検証と移動AIを整合。
- 既存の敵バランスv6をv7へ一度だけ移行。セーブスキーマ12とアイテムテンプレートは維持。

詳細: [PATCH_NOTES_v5.2.2.md](PATCH_NOTES_v5.2.2.md)

## v5.2.1 パッチ修正

- 敵同士が進路を塞いだ時、空いている隣接マスへ小さく回避して再接近するようにし、無関係な方向へ大回りする動きを抑制。
- プレミアム報酬でも現在階より先のアイテムテンプレートは選ばず、強化品質だけを上げるように変更。
- プレイヤーの全ターン操作に短い間を追加。ゲームオーバー時は最後の被弾表示を残してから結果画面に切り替え。
- 探索中にボスBGMを先読みし、ボス階への切り替えを高速化。

詳細: [PATCH_NOTES_v5.2.1.md](PATCH_NOTES_v5.2.1.md)

## 全フロアの敵バランス

各ダンジョンの1階から最終階まで、平均的な敵戦闘力の目標を滑らかな曲線で上げます。

| 難易度 | 1階の目標 | 最終階の目標 |
|---|---:|---:|
| チュートリアル | 58% | 62% |
| 初級 | 62% | 65% |
| 中級 | 70% | 76% |
| 上級 | 67% | 73% |
| 最上級 | 78% | 84% |

敵能力補正の上限は通常4難易度で1.19、最上級で1.38です。上級の個体目標値は元のまま維持し、他の難易度を小幅に引き上げています。上級は元から中級より通常敵数が多いため、個体目標値の順番とフロア全体の圧力を分けて評価します。

敵の通常出現数・ボス支援数は変更していません。個体の基本補正を共通のまま保ち、難易度目標値だけを小幅に引き上げています。

## 冒険開始時の食料

新しい冒険では、既存の1階向け食料テンプレートから1つを所持して開始します。新しい食料アイテムは追加していません。初期装備もありません。

## これまでの改善

- モンスターが階段マスを経由して追跡できるように修正。
- ドラゴンのブレスをモンスター起点の射線として描画・判定し、射線上の敵にもダメージを与えます。
- モンスター専用のレベルアップファンファーレを追加。
- 武器の耐久消耗を2回の攻撃につき1回に緩和。
- 反射特性の希少個体を追加。
- 金貨の通常ドロップ率を0.88倍に抑え、装備・換金品・薬・食料のドロップ率を調整。
- 地面の武器・盾・鎧・食料・薬・換金品を種類別のシルエットで表示。

## セーブ互換性

通常敵のバランスバージョンをv7へ更新します。既存敵の現在HP割合を保ち、v1〜v6それぞれの旧補正から差分移行します。セーブスキーマ12とボス本体の基本性能は維持します。
