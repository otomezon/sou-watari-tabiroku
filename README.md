# 層渡りの旅録 v5.1.21

最上級の序盤を段階的に調整し、敵の追跡・ブレス・報酬・装備耐久とアイテムの見分けやすさを改善しました。

- 最上級の平均敵戦闘力目標を1〜5階で72%から82%へ段階的に戻し、5階以降は従来目標を維持します。
- 全キャンペーンで新しい冒険におむすびを1個追加。回復量は満腹度40です。初期装備は追加しません。
- 通常敵・店主・レア敵の経路探索から階段マスの通行禁止を外し、階段を経由して追跡できるようにします。
- ドラゴンのブレスを敵の位置からプレイヤーまでの直線マス列として判定・描画し、射線上の敵にもダメージを与えます。
- モンスターのレベルアップ音をプレイヤーより低い5度の音程と柔らかな音色に分離します。
- 武器の耐久減少を2回の攻撃につき1回に緩和します。
- 既存のレア特性に、受けた攻撃の一部を返す「反響」個体を追加します。
- 金貨の通常ドロップ率を係数0.88で抑え、装備・薬・食料のドロップ率を上げます。
- 地面の武器・盾・鎧・食料・薬・換金品を種類別のシルエットで描画し、おむすびは三角形で識別できます。
- v4敵セーブは倍率を二重適用せずv5へ移行します。セーブスキーマ12とボス本体の基本性能は維持します。
