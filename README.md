# 層渡りの旅録 v5.1.17

5行動ごとの空腹減少に対応し、減少まであと1行動の状態も正しく保存・再開できるようにしました。各階の敵レベル・縦長ブレス・効果音調整も引き続き有効です。

- 平均55%の敵を倒すプレイを想定し、装備なしのプレイヤー実戦力と各階の敵集団の実戦力を比較。難易度別に補正し、敵能力の補正幅は+8%〜-15%に制限します。
- 既存セーブの現在フロアに残る通常モンスターはHP残量割合を維持して一度だけ新補正へ移行。セーブスキーマ12を維持します。
- 満腹度の減少を4行動ごとから5行動ごとに変更。
- レベルアップファンファーレ中に被弾音も同時に再生。複数回の被弾音はファンファーレ中に短く間隔を空けて鳴ります。
- ドラゴン系のブレスを、着弾マス中心の縦長3×5マス範囲攻撃に変更。予告表示と命中範囲を統一しました。
