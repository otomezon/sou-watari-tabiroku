# 層渡りの旅録 v5.0.6

レア個体の出現率をさらに引き上げ、ゴールド獲得量を元に戻しつつ、アイテム報酬を補強するパッチです。

- レア個体の総出現率を初級8.5%、中級9.5%、上級10.5%、最上級11.5%へ上昇。
- ゴールドドロップ率はv5.0.5の設定を維持し、獲得量倍率は通常個体0.85倍、レア個体2.0倍へ復帰。
- 装備・換金品・薬・食料の通常ドロップ率をわずかに上昇。
- 魔喰い専用の80%プレミアム戦利品テーブルを追加。剛腕・俊敏よりも豪華な報酬を得やすくしました。
- チュートリアルのレア個体なし、初級の魔喰いなしを維持。
- セーブスキーマ12を維持。既存の冒険データをそのまま利用できます。
