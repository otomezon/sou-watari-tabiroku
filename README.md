# 層渡りの旅録 v4.8.4

回復・ドロップ・敵レベル進行・倍速個体のバランスを調整したパッチリリースです。

- 食料の満腹度回復量1.25倍、ポーションのHP回復量1.75倍（付随満腹度は据え置き）
- フロア内装備率+2ポイント、ポーション率-2ポイント
- 通常敵・希少敵の装備ドロップを少し増加、ポーションを少し減少
- 隣接Tierをsmoothstepで混合し、敵レベルのフロア進行を平滑化
- 倍速敵の能力を微調整。2回行動は維持
- セーブスキーマv11を維持し、旧セーブ内回復アイテムにも新倍率を適用
