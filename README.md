# 層渡りの旅録 v5.0.0

魔喰いレアモンスター、モンスター同士の戦闘・成長AI、アイテムの隣接マスへの安全なドロップ配置を追加したメジャーアップデートです。

- 魔喰いは通常モンスターを探して攻撃し、倒すたびにレベルと能力が上昇します。
- 討伐地点にアイテムが既にある場合、新しいドロップは空いている上下左右の隣接マスへ移動します。
- メッセージ表示部の高さと位置を1px単位で微調整しました。

既存の冒険データはスキーマ12へ自動移行し、現在の階層・持ち物・装備を引き継ぎます。
