# 層渡りの旅録 v5.0.4

魔喰いの戦闘能力を一段階引き上げ、特に耐久力を強化したパッチリリースです。

- 魔喰いの初期HP倍率を1.30倍から1.70倍へ、攻撃倍率を1.15倍から1.25倍へ上昇。
- 魔喰いの初期防御力を+2から+6へ強化。
- 魔喰いが通常モンスターを倒して成長する際、HP上昇量を最大HPの12%から18%へ増加し、防御力も毎レベル+1。
- その他のモンスター、出現率、ドロップ率は変更していません。
- セーブスキーマ12を維持。既存の冒険データをそのまま利用できます。
