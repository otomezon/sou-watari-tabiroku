# 層渡りの旅録 v5.1.20

通常敵の撃破率を50%とする中間的な成長想定に戻し、前回の弱体化しすぎを修正しました。敵のHP・攻撃・防御を一律に上下させず、戦闘の長さと被ダメージを別々に調整しています。

- ボス階到達時の想定プレイヤーLv：チュートリアル3／初級8／中級14／上級23／最上級30
- 難易度別の平均敵戦闘力目標（装備なしプレイヤーの基礎戦闘力に対する重み付き指標。上級は敵数と上位ランクの移行が中級より厳しいため、中級と同じ平均目標に設定）：54%／62%／70%／70%／86%
- 敵の基礎スケールに対し、HP×1.08・攻撃×0.92・防御×0.95を個別適用。さらに通常敵の防御は、想定レベルの素の攻撃力を基準に上限を設け、高防御個体が装備必須の壁になるのを防ぎます。敵補正の下限も0.60にし、最上級序盤などが弱くなりすぎないようにします。
- レア個体は特徴を維持して強さを一部戻し、通常敵との差を明確にします。
- 既存セーブの敵バランスv1／v2／v3をv4へ差分移行し、現在HP割合を維持します。
- ボス本体の難易度別性能、セーブスキーマ12、固定回復量、満腹度5行動ごとの減少、縦1×5ブレスは維持します。
