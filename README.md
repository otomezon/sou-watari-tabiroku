# 層渡りの旅録 v5.1.16

階層ごとの想定プレイヤーレベルを、通常モンスターを約90%倒して進むプレイを基準に再調整しました。

- 全5難易度・全フロアの敵Lvと通常敵の能力補正を再設定。既存セーブの敵Lvも読み込み時に補完します。
- レベルアップファンファーレと被弾音を同時再生し、満腹度は5行動ごとに1減少します。
- ドラゴン系の炎・氷ブレスは横幅1マス、縦3マスの細い範囲攻撃です。
- セーブスキーマ12は維持しています。
