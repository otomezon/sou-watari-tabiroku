# 層渡りの旅録 v4.9.0

探索画面・敵ビジュアル・サウンドを強化するマイナーアップデートです。

- 60種類の通常モンスターを複数のピクセルシルエットに描き分け、輪郭・パーツ・姿勢にも差を付与。
- 探索エリア直下の凡例2行（「あなた～お金」「Lv＝敵の能力値目安・希少個体～」）を削除し、キャンバスの表示領域を拡張。
- プレイヤーの攻撃音を金属的な斬撃音に、被弾音を低音の衝撃＋中音の打撃音に変更。
- 被弾音の再生間隔を広げ、倍速敵の2回攻撃が2発として聞こえるよう調整。
- レベルアップのファンファーレを新規オリジナルWAV音源へ更新。オフラインキャッシュにも追加。
- セーブスキーマv11を維持。既存セーブの移行は不要。

## Hosting
Cloudflare PagesはGitHub連携でmainブランチへの更新を自動デプロイします。公開ルートはリポジトリ直下のindex.html、assets/、audio/、icons/、sw.js、manifest.webmanifestです。
