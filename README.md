# 層渡りの旅録 v4.9.2

v4.9.1からのサウンド修正パッチです。

- レベルアップファンファーレを再設計。単純な上昇音階ではなく、Dメジャーの IV–V–I（G→A→D）で終止する、約3秒のオリジナルジングルに変更しました。
- 短い旋律の呼応、金管風リード、柔らかな三和音の伴奏、低音のアクセント、最後のベルを組み合わせています。Web Audio APIで合成するため、追加の音声ファイルをダウンロードせずオフラインでも再生できます。
- 『風来のシレン6』の独立したレベルアップ・ジングル、『トルネコの大冒険』のレベルアップ曲、JRPGファンファーレの終止感を参考に、既存曲の旋律や録音は使わずに作曲しています。
- 主人公が攻撃して敵を倒した際も、攻撃音を必ず再生するように修正しました。
- 敵を倒したことだけを理由に鳴らしていた「defeat」効果音を削除しました。レベルが実際に上がった場合のファンファーレは引き続き鳴ります。
- 攻撃でレベルアップ・被弾・ゲームクリア／ゲームオーバーが同時に起きる場合も、攻撃音→レベルアップ音→被弾音→結果音の順に並べます。
- セーブスキーマv11を維持。バランス、敵AI、既存セーブデータへの変更はありません。

## Hosting

Cloudflare PagesはGitHub連携でmainブランチへの更新を自動デプロイします。公開ルートはリポジトリ直下のindex.html、assets/、audio/、icons/、sw.js、manifest.webmanifestです。
