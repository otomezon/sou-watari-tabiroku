# 層渡りの旅録 v5.1.16

階層ごとの想定プレイヤーレベルに合わせて敵レベルを調整し、空腹・効果音・縦長ブレスの挙動を改善しました。

- 回復薬はv5.1.11変更前のアイテム定義値と1.75倍補正に復帰。最大HPに依存しない固定HP回復です。
- チュートリアルは1×1・護衛なし・特殊攻撃なし。初級は小型、中級は従来相当、上級は3×3、最上級は4×4のボスにしました。
- 上級以上は5×5の大技とHP低下時の強化段階を追加。ボス階の護衛数も難易度に応じて増やし、低確率で希少個体が混ざります。
- 既存のボス戦セーブは残りHP割合を維持して一度だけ更新し、自動保存します。
