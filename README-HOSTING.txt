層渡りの旅録 v4.7.3 — 静的ホスティング用

このフォルダ内の全ファイル・フォルダを公開ディレクトリ直下へ配置してください。
index.html、assets/、audio/、icons/、sw.js、manifest.webmanifest が同じ階層に並ぶ構成です。
HTTPSで配信するとPWAインストール・Service Worker・オフラインキャッシュが利用できます。

v4.7.3: 店内の商品操作は「拾う」「戻す」のみ。拾った商品はすべて購入対象となり、残った商品は「まとめて購入」で一括精算します。「選択」「解除」はありません。
未払い商品を戻すと、所持品または装備から対象だけを除き、棚へ復帰させてその商品価格分だけ負債を取り消します。
セーブスキーマv11を維持し、v4.7.1/v4.7.2のセーブと互換です。

検証: Node 108/108、レイアウト10/10、店舗27/27、ブラウザTypeScript PASS、スタンドアロンプレビュー PASS。
