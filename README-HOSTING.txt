層渡りの旅録 v4.7.2 — 静的ホスティング用

このフォルダ内の全ファイル・フォルダを公開ディレクトリ直下へ配置してください。
index.html、assets/、audio/、icons/、sw.js、manifest.webmanifest が同じ階層に並ぶ構成です。
HTTPSで配信するとPWAインストール・Service Worker・オフラインキャッシュが利用できます。

v4.7.2: 店内で未払い商品ごとに「戻す」が使えます。商品を所持品または装備から取り除いて元の棚へ戻し、その商品の価格分だけ未払い額を減らします。ほかの未払い商品と購入対象の選択は維持します。
未払い商品は個別管理され、通常の売却はできません。v4.7.1の同種スタック統合済みセーブは安全な互換処理を行います。消費済み商品は返却できません。
セーブスキーマv11を維持しています。

検証: Node 108/108、レイアウト10/10、返却パッチ11/11、PWA静的24/24、HTTPアセット26/26。
