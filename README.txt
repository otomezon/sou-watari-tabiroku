層渡りの旅録 v4.7.2 — standalone preview

起動方法:
1. ZIPを展開します。
2. 展開したフォルダで python3 -m http.server 8000 を実行します。
3. http://localhost:8000/ を開きます。

PWAインストール・Service Worker・オフライン起動には localhost または HTTPS が必要です。
ZIP内の index.html を file:// で直接開かず、HTTPサーバーで配信してください。
ホスティングではこのフォルダの中身を公開ディレクトリ直下へ配置してください。

主な内容:
- 5キャンペーン: チュートリアル5階 / 初級10階 / 中級15階 / 上級25階 / 最上級30階。チュートリアルは敵倍率0.92、Tier1敵能力を強化。
- 非ボス階の魔物数は各階ごとに独立抽選: チュートリアル3〜5体、初級4〜7体、中級5〜8体、上級5〜9体、最上級6〜10体。最終階はボス1体に加えて、キャンペーン別に通常魔物1〜3体。画面に残存数は表示しない。
- 60種類のモンスター、90種類のアイテム（武器22 / 盾16 / 防具13 / 回復薬14 / 食料20 / 換金品5）。非ボス階はキャンペーン別の範囲から毎階独立抽選。最終階には専用ボスに加え通常魔物1〜3体が出現。残存数は画面に表示しない。
- 5ダンジョンBGM（チュートリアル←現初級、初級←現中級、中級←現上級、上級←現最上級、最上級←現チュートリアル）、v2ボスBGM、レベルアップファンファーレ、ゲームオーバー音。全音源をローカル収録しオフラインキャッシュ。
- ランダムなアイテム屋: キャンペーン別5〜10%、各フロア最大1軒、商品4〜6点。装備40%、回復薬30%、食料30%。各商品は「拾う」で所持品へ取り置き、別の「選択中を購入」ボタンで個別精算。未払い商品の「戻す」で元の棚へ戻し、その商品の価格分だけ負債を取り消す。未払い品は個別識別され、売却不可。所持金不足時は購入ボタンを無効化し、未払いのまま退店すると店主が追跡。
- 装備品は深層ほど強化値と基本性能が上昇。1〜3階の通常装備は+0〜+2、premium装備は+0〜+3に制限。premium候補の先取りは1〜2階で0階、3〜5階で1階、6〜11階で2階、12階以降で最大3階。
- 店主「石翼の番商」は倍速・HP420。攻撃力は14 + floor×1.1 + round(difficultyScale×2)へ強化、防御式は維持。店内boundsならどこからでも店主ボタンで会話可能。
- 換金専用アイテム5種: 琥珀の欠片180G / 銀細工の聖櫃420G / 月長石850G / 竜珠1650G / 星晶核3200Gを基準に高値売却。
- 通常敵のアイテムドロップは装備1.0〜1.3%、換金品0.2〜0.8%、回復薬2.4〜3.2%、食料1.4〜2.8%。希少鈍足/倍速敵は装備18% / 換金品7% / 回復薬5% / 食料5%（合計35%）のpremium戦利品判定。
- 通貨G。通常敵の金貨ドロップ率24〜40%、金額12+floor×3〜30+floor×7。通常敵の獲得量0.85倍、希少敵は2倍。歩行による自動回収、死亡時所持金ロスト。
- 新規装備の最大耐久は min(600, baseDurability + baseStat×7 + enhancement×12)。高性能装備ほど長持ち。
- 倍速モンスターの各攻撃が命中するたび被弾音を再生。2回命中すれば2回。
- 階段へ敵が侵入しない経路探索。旧セーブの階段重複敵を安全な床へ退避。
- 縦画面専用、画面固定、ページスクロール禁止。幅最大340pxの大きな十字キー。ゲーム下部は持ち物・装備、店主（左）・設定（右）、階段を配置し、設定の独立行を削除して探索Canvasを縦に拡張。
- 満腹度120、4行動ごとに1減少。満腹HP回復は9ターンごと、飢餓ダメージは6ターンごと。
- IndexedDBオートセーブ、セーブスキーマv11（v1〜v11互換）。旧v4.5.0の未払い商品の状態を新方式へ正規化。
